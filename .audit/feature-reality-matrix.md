## Bottom line

- Source reality is strong for implementation and mounting across the documented major feature set.
- Feature availability is conditional: tenant flags/modes, permissions, subscription state, worker env flags, third-party credentials, and production frontend env all matter.
- No row above is marked production-enabled merely because code exists, a route is mounted, a default is true, or a guide says production uses it. Production-enabled/runtime verification remains unknown or deferred until deployment configuration and live behavior are read back directly.
