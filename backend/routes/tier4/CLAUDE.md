# Tier 4 Routes — Claude Guide

- **7 files** — premium features, all use factory pattern: `module.exports = function(deps)`
- **`index.js`** — aggregator, composes all sub-routers into one Express router
- **`accounting.js`** — P&L, COA, cheques, journal entries. Guards: `requireFeature("accounting_core")` + `requireAnyPerm(["view_reports", "manage_employees"])` for most routes. **Exception**: COA (chart of accounts) routes require `requireAnyPerm(["all_access"])` + `accounting_core`; cheques require `requireAnyPerm(["manage_employees","all_access"])` + `accounting_core`. Uses `toUtcStart/toUtcEnd` for date boundaries
- **`approvals.js`** — PO/transfer approval workflow + reconciliation approval. Guard: `requireFeature("approvals")`. PO submission is transactional (status + `approval_requests` atomically). Only `"Draft"` POs can be submitted. Also exposes `GET /api/approvals` (list requests by status, defaults to `"pending_approval"`) and `POST /api/reconciliation/inventory/:id/approve-fix` (requires `requireAnyPerm(["manage_inventory","all_access"])`)
- **`crm.js`** — Leads + activities + quotations. Guards: `requirePerm("manage_orders")` + `requireFeature("crm_quotations")`. Includes `POST /quotations/:id/send` (emails quotation via SMTP directly — bypasses `services/email.js`), `DELETE /quotations/:id`, `PUT /quotations/:id/status`, `POST /crm/leads/:id/convert` (lead-to-customer)
- **`hr.js`** — Leave requests + payroll. Guards: `requirePerm("all_access")` + `requireFeature("advanced_hr")`. Creates notification on leave submission. Also exposes `GET /api/hr/leave/balance` (monthly leave balance). Leave approval checks for schedule conflicts in `scheduled_shifts`
- **`notifications.js`** — `GET` (list), `GET /count`, `PUT /:id/read`, `PUT /read-all`. Guard: `requireFeature("notifications")` only — no `requirePerm` guard (any authenticated user). Supports `?unread_only=1`. No POST, DELETE, or PATCH routes exist
- **`company-profile.js`** — GET/PUT company settings. `GET /api/company-profile` and `PUT /api/company-profile` require `requireFeature('multi_company')`; PUT also requires `requirePerm('all_access')`. Additional: `PUT /api/company-profile/onboarding-dismiss` (`all_access`, no feature flag), `POST /api/company-profile/logo` (`all_access` + `multi_company` — multer upload, **POST not PUT**). `GET /api/company-profile/currency` is **unauthenticated** (accepts `?tenant=slug` in MT mode). Currency endpoint returns `cash_denominations` JSON with fallback `[100,50,20,10,5,1]`
