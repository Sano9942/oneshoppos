# Routes — Claude Guide

- **4 files** — React Router route definitions split by access level
- **`publicRoutes.jsx`** — `/` (HomeRedirect — checks setup status), `/setup`, `/login`, `/reset-password`, `/signup`, `/receipt/:invoiceNumber`, `/access-denied`, `/context-select` (requires auth), `/pos` (requires auth + ErrorBoundary), `/kiosk` (requires auth + ErrorBoundary), `/customer-display`. Also: `/store/:tenantSlug` (public storefront, 6 nested routes), `/book/:tenantSlug` (public booking), `/menu/:token` (public restaurant menu)
- **`appRoutes.jsx`** — ~90+ lazy-loaded pages nested under `RequireAuth > RequireContext > AppLayoutRedesign`. Permission shortcuts via `perm(permString, element)` and `wrap(Component)` helpers. Includes Wave 2–5 competitive features (accounting, stock counts, price lists, loyalty, fulfillment, review moderation, COD settlements), Phase 2B (report builder, POS layouts, commissions, smart collections), Phase 3 (marketing campaigns, messaging inbox, customer invoices, subscriptions), Phase 4 (restaurant floor/checks, KDS, kiosk-ordering, appointments, projects, contracts). Notable integration routes: `/settings/integrations` (IntegrationsHubRedesign, perm: manage_inventory), `/integrations/shopify`, `/integrations/woocommerce`
- **`adminRoutes.jsx`** — `/admin/login`, `/admin` (dashboard), `/admin/tenants`, `/admin/tenants/:id`, `/admin/support`, `/admin/emails`, `/admin/dead-letters`, `/admin/tax-rates`, `/admin/activity`. No `RequireAuth` — admin auth checked inside `AdminLayout` via `getAdminToken()`
- **`RouteLoading.jsx`** — centered "Loading..." box, used as `Suspense` fallback
