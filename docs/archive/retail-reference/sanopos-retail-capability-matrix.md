# SanoPOS Retail Capability Matrix - 2026-04-23

This is the **primary truth source** for retail capability claims. It translates code surfaces into merchant outcomes and marks each capability by gate, evidence, maturity, and claim boundary.

Use together with:

- [docs/audits/sanopos-retail-gap-audit-2026-04-23.md](audits/sanopos-retail-gap-audit-2026-04-23.md) for what the previous report missed or misframed

## Legend

- `Gate`: `default-on`, `feature-flag`, `plan/tier`, `connection-based`, `admin-only`
- `Evidence`: combinations of `Code`, `UI`, `Tests`
- `Maturity`: `Shipped`, `Flagged`, `Partial`, `Internal-only`
