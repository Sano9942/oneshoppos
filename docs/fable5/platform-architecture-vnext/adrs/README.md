## Status model

- **Proposed:** awaiting product and architecture approval
- **Accepted:** authoritative target decision
- **Superseded:** replaced by a later ADR; retained for history
- **Deprecated:** no longer recommended but still relevant during migration

An ADR is changed by superseding it, not by silently rewriting its accepted decision.
